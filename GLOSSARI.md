
Backlog

• Anglès: Backlog
• Definició: Llista prioritzada on s'acumulen totes les tasques, millores i errors detectats que s'hauran d'anar resolent al llarg del projecte.
• Exemple: Vam revisar el backlog de GitHub Projects per decidir quines tasques col·locàvem al primer sprint.

Clone

• Anglès: Clone
• Definició: Còpia local i exacta d'un repositori remot que es descarrega a l'ordinador de treball per poder modificar els arxius de manera interna.
• Exemple: Vaig fer un clone del repositori de l'equip a la meva terminal per començar a programar el codi a la meva màquina.

Commit

• Anglès: Commit
• Definició: Registre permanent o instantània que desa els canvis que hem fet en el codi, acompanyat sempre d'un missatge que explica què s'ha modificat.
• Exemple: Després de corregir l'error de la interfície, vaig fer un commit amb el missatge "Fix: resolt l'error de disseny".

Field

• Anglès: Field
• Definició: Atribut o columna de metadades personalitzable que s'afegeix a les tasques de GitHub Projects per poder classificar-les o filtrar-les millor.
• Exemple: Vam crear un field nou de tipus text anomenat "Prioritat" per saber quines tasques eren urgents.

Fork

• Anglès: Fork
• Definició: Còpia independent d'un repositori que es vincula al nostre compte de GitHub, permetent-nos modificar-lo lliurement sense permís d'escriptura a l'original.
• Exemple: Vam fer un fork de pallets/flask per poder-hi pujar canvis.

Issue

• Anglès: Issue
• Definició: Unitat de treball o tiquet de GitHub que s'utilitza per documentar una tasca, una idea, un requeriment o un error pendent de resoldre.
• Exemple: Vaig obrir un issue a GitHub per demanar als meus companys que repensessin el disseny del formulari d'accés.

Iteration

• Anglès: Iteration
• Definició: Tipus de camp especial de GitHub Projects que s'utilitza per definir calendaris o blocs de temps de treball consecutius dins d'un projecte.
• Exemple: Vam configurar l'iteration a la taula de GitHub per dividir els terminis d'entrega de les properes setmanes.

Kanban

• Anglès: Kanban
• Definició: Sistema visual de gestió de treball basat en columnes que representen l'estat d'una tasca, utilitzat per limitar la feina en curs i evitar colls d'ampolla.
• Exemple: Fem servir un tauler Kanban a GitHub per veure d'un sol cop d'ull quines tasques estan en procés i quines ja s'han completat.

Pull Request

• Anglès: Pull Request (PR)
• Definició: Petició formal que es fa a GitHub per demanar que les teves línies de codi noves o modificades es revisin i s'incorporin al repositori principal.
• Exemple: Vaig obrir una pull request per integrar la meva branca de desenvolupament amb la branca 'main' de l'equip.

Repository

• Anglès: Repository
• Definició: Carpeta o espai d'emmagatzematge virtual a Git/GitHub on es guarden tots els fitxers d'un projecte i el seu historial sencer de modificacions.
• Exemple: Vam crear un nou repository a GitHub per poder allotjar i compartir tot el codi de la nostra pràctica d'Scrum.

Scrum

• Anglès: Scrum
• Definició: Metodologia àgil de gestió de projectes caracteritzada per la col·laboració intensiva de l'equip i el lliurament de feina de manera incremental en períodes curts.
• Exemple: Apliquem la metodologia Scrum a classe per dividir el desenvolupament de la nostra aplicació en objectius clars.

Sprint

• Anglès: Sprint
• Definició: Cicle de treball tancat i de durada fixa en el qual l'equip es compromet a transformar un conjunt de tasques seleccionades en un lliurable funcional.
• Exemple: Hem organitzat la pràctica en 2 sprints de tres setmanes cadascun per tal de repartir equitativament les entregues.

Sprint Backlog

• Anglès: Sprint Backlog
• Definició: Conjunt de tasques triades específicament del backlog general que l'equip es compromet a enllestir durant l'sprint que tot just comença.
• Exemple: Les tasques de l'Sprint 1 passen a la columna Sprint Backlog per tenir clar què farem en aquest primer període.

Status

• Anglès: Status
• Definició: Camp que indica l'estat actual en què es troba un tiquet o un issue (com ara "Per fer", "En progrés" o "Fet") dins d'un flux de treball.
• Exemple: Quan vaig acabar de programar la funció de registre, vaig canviar el seu status a "Done".

User Story

• Anglès: User Story
• Definició: Descripció breu i senzilla d'una funcionalitat redactada des del punt de vista de l'usuari final per entendre el valor que li aporta.
• Exemple: Vam redactar una user story que deia: "Com a usuari, vull rebre un correu per recuperar la meva contrasenya".
